## Ali Mahdi

PhD researcher in fluid mechanics and artificial intelligence at **CORIA**
(UMR 6614 CNRS), Université de Rouen Normandie.

[![ORCID](https://img.shields.io/badge/ORCID-0009--0005--0208--5479-A6CE39?logo=orcid&logoColor=white)](https://orcid.org/0009-0005-0208-5479)

My work brings together computational fluid dynamics and machine learning,
applied to free-surface flows and wave–structure interaction. I use OpenFOAM to
resolve the flow over coastal structures such as dikes, seawalls and
rubble-mound breakwaters.

### Current work

**[COAST](https://github.com/alimahdiiii/COAST)** — Coastal Overtopping Analysis
and Simulation Toolkit. A Streamlit application that automates the whole OpenFOAM
pipeline for wave overtopping simulations, from parametric geometry and mesh
generation through to event-by-event post-processing.

### Interests

Computational fluid dynamics · machine learning · free-surface flows (VOF) ·
wave–structure interaction · overtopping discharge and event statistics ·
OpenFOAM automation
